# Analysis with Spotify API 

This repository contains several analysis projects using the **Spotify API**. The current projects focus on:  

- **Top 50 Most Streamed Songs Tree Visualization**:  
  - Generates a **Spotify tree map** based on the most streamed 50 songs.  
  - Uses data visualization techniques to display song popularity hierarchically.  

- **Personalized Song Recommendation**:  
  - Recommends songs based on user likes and listening history.  
  - Fetches and analyzes user preferences via the Spotify API.  

🚧 **Work in Progress** 🚧  
The projects are still being updated with improvements and new features. Stay tuned for further enhancements!
